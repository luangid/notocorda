# Fidelizar cliente

## Definição

Transformação necessária: o cliente volta e recomenda a loja a outras
pessoas.

## Papel no negócio

Fecha o ciclo de valor devolvendo o resultado da experiência para o
objetivo de negócio — é o que sustenta a receita futura, não só a
venda do dia.
