# Servir café com qualidade e margem

## Definição

Resultado desejado: servir bebidas dentro do padrão da casa, com uma
margem que sustente o negócio no longo prazo.

## Papel no negócio

É o objetivo para o qual toda a cadeia de valor converge. Cada etapa —
de abastecer a operação até fidelizar o cliente — existe para produzir
esse resultado de forma repetível.

## Relações

Nenhuma relação de saída: é o destino do eixo de valor (etapas avançam
até aqui por `advances`).
